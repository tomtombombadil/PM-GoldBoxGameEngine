Put your own Gold Box games here - one folder per game.

Copy each game's whole install folder (the GOG or Steam release) into this
folder, as it is. For example:

    games/Pool of Radiance/
    games/Curse of the Azure Bonds/
    games/Secret of the Silver Blades/
    games/Pools of Darkness/

The folder's name tells the port which game it is, so keep the game's name
in it. Then start "Gold Box Game Engine" from your Ports menu.

Saved games are written into each game's own folder, as the original games
did. The folder _CYD is the engine's own (files it makes from your games);
it can be deleted - the engine makes it again.

This port contains nothing from the games themselves. You need your own
copies.
